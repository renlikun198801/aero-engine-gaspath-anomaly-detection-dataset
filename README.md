# aero-engine-gaspath-anomaly-detection-dataset
Simulated twin-spool turbofan gas-path dataset for one-class anomaly detection: 5 measurement-noise levels (0×–10×) × train/val/test splits, 12 gas-path measurements plus 5 flight-condition inputs, and 8 single-component degradation modes. Labels: 1 = healthy, −1 = anomalous.
